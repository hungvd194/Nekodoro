# Nekodoro — production assets

- `src/PomodoroTaskbar.Windows/Assets/Cat-sprite.png`: generated with the built-in imagegen tool, original mascot using approved `concept-v1.png` as style/identity reference. True alpha, 1536×1024 pixels; 3×2 cells.
- Reading order: idle, focus/reading, paused, short break/tea, long break/asleep, completed/waving.
- `MascotArt.cs` slices the sheet at runtime into six frozen cached `CroppedBitmap` frames. No image-generation call or animation loop occurs in the shipped app.
- `Assets/App.ico` and `Assets/App.png`: code-drawn simplified cat face matching the mascot's cream/gray-brown/tomato palette. Regenerate with `scripts/Generate-Icon.ps1`; ICO contains 16, 20, 24, 32, 48, 64, 128 and 256 px frames.

## Sprite prompt

Generate a PRODUCTION TRANSPARENT SPRITE SHEET of six separate original Nekodoro mascot cat illustrations, using the supplied UI concept ONLY as character identity and illustration style reference. Do not reproduce any UI, controls, text, window or background. Preserve this exact original cream cat with gray-brown ear/back patches, little tomato on head, tiny black dot eyes, dark softly irregular outline, friendly slightly clumsy hand-painted Irasutoya-inspired Japanese clipart aesthetic, faint paper grain INSIDE painted areas. Sheet layout is strict 3 columns by 2 rows of six equal-sized cells, landscape 1536x1024 if possible, each cell512x512. All six poses have the SAME apparent size, centered in its cell, ample transparent margin at every edge, no overlap between cells. Reading order: TOP LEFT seated relaxed cat next to small tomato timer (idle); TOP CENTER same cat reading an open sage-green book (focus); TOP RIGHT same cat putting book down and looking up patiently (paused); BOTTOM LEFT same cat holding a small tea mug (short break); BOTTOM CENTER same cat curled asleep (long break); BOTTOM RIGHT same cat waving one paw happily (completed). Clean separate cutouts without floor shadow, no furniture, no plant, no props except the mentioned small book/timer/mug. True transparent alpha outside characters, no white rectangles, no checkerboard drawn, no gridlines, no cell borders, no captions, no words, no watermarks. This is one sprite sheet to be cropped by the desktop renderer, not an illustrative poster. Make each complete silhouette stay well inside its cell.
